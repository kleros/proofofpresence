# Static proposal previews

These seven PNGs are document renders of initialized prototype states, not browser screenshots. Desktop artboards are 1440px wide; the mobile artboard is 400px wide. Preview height varies and must not be reported as completed 1440×900 or 400×800 browser validation.

The export uses the embedded fonts and assets, resolves viewport-dependent type sizes, substitutes static anchors for native button presentation, preserves the disabled-state treatment, and normalizes stacked/timeline layout for the document renderer. These adaptations support a legible review PDF and do not establish browser layout behavior. See `../QA_REPORT.md` for exact execution and pending checks.

The original HTML is the interaction reference. Its synthetic review controls never connect to wallets, RPCs, Luma, email, or production storage.
