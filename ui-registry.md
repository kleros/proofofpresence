# Kleros event workbench visual registry

New UI established 28 October 2026. Captured with the imprint skill after building `public/index.html`, `public/app.js` and `public/styles.css`. The retained legacy apps keep their existing designs; these patterns govern the unified local workbench.

### Shell and typography

File: `public/styles.css`
Last updated: 28 October 2026

| Property | Token / selector |
|---|---|
| Page background | `--paper: #f6f5f8` |
| Sidebar | `--purple-deep: #2b174d`, `.sidebar` |
| Primary text | `--ink: #221934` |
| Secondary / quiet text | `--muted: #736d7d`, `--quiet: #948e9d` |
| Font | System sans stack; code uses system monospace |
| Headings | `h1` 28–41px / 620, `h2` 22px / 620, `h3` 16px / 650 |
| Body / labels | 14px body; 12px panel body; 12px / 600 labels |
| Brand accent | `--purple: #6235b5`; pale violet `--purple-soft: #f0eafa` |

Pattern notes: Restrained type hierarchy, high contrast dark text, small uppercase context labels. Event identity, local environment, contract and wallet remain explicit without placing engineering details in the primary event headline.

### Cards and panels

File: `public/styles.css` / generated by `public/app.js`
Last updated: 28 October 2026

| Property | Token / selector |
|---|---|
| Background | `--surface: #fff`, `.panel`, `.event-card` |
| Border | 1px solid `--line: #e8e4ed` |
| Radius | `--radius: 14px`; inner blocks `--small-radius: 9px` |
| Text | `--ink` primary, `--muted` descriptions |
| Spacing | 24px card/panel padding; 20–23px adjacent gaps |
| Hover | Event cards translate -2px and use `--shadow` |
| Shadow | `0 14px 48px #25143b12`; panels normally none |
| Accent | Event visuals violet/sage, patterned with CSS geometry |

Pattern notes: Information panels are white with a fine border. Inner status and amount blocks use pale neutral/violet. Color marks status and context; it is never the only status signal.

### Buttons, inputs and focus

File: `public/styles.css`
Last updated: 28 October 2026

| Property | Token / selector |
|---|---|
| Primary button | `.button-primary`, violet fill/white text |
| Secondary button | `.button-secondary`, white fill/fine border |
| Danger action | `.button-danger`, `--red-soft` fill / `--red` text |
| Radius | `--small-radius: 9px` |
| Text / padding | 12px / 580; 11px 17px padding |
| Hover | 1px lift; darker primary or pale secondary |
| Focus | 3px `#b695ef` outline with 3px offset |
| Disabled | 48% opacity, not-allowed cursor |
| Input | White, 1px `--line`, 10px 12px padding, same radius |

Pattern notes: Financial writes first open a transaction review. Confirm is the violet primary button; Cancel is a secondary button. Server denial appears as concrete text without implying a successful state.
