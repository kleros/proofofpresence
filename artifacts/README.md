# Public verification fixtures

This directory retains only the twelve public JSON inputs required by the backend
or existing tests: four pinned wallet-verification proofs, two event/QR fixtures,
one creation-review fixture and five historical rehearsal fixtures.

The backend verifies the pinned proof files and related verifier/test sources by
hash. Keep their paths and bytes intact. Generated reports, logs, screenshots,
archives and private runtime state stay outside the published source.
